# Precios en Efectivo - Mobile Store Ecuador

Sitio estático con las listas de precios en efectivo de Mobile Store Ecuador (Agosto 2026).

## Páginas

- `index.html` → Menú principal
- `apple.html` → Lista de precios Apple (iPhone, MacBook, etc.)
- `smartphones.html` → Xiaomi, Honor, Samsung
- `laptops.html` → Laptops y accesorios

## Cómo publicar en GitHub Pages

1. Crea un repositorio nuevo en GitHub (ejemplo: `precios-mobilestore`)
2. Sube todos los archivos de esta carpeta
3. Ve a **Settings → Pages**
4. En "Source" elige **Deploy from a branch**
5. Selecciona la rama `main` y carpeta `/ (root)`
6. Guarda

Tu sitio estará en:  
`https://TU-USUARIO.github.io/precios-mobilestore/`

## Notas

- Los precios se extrajeron de las plantillas de Elementor de Agosto 2026.
- Las imágenes se cargan desde mobilestore.ec
- Confirma siempre stock y precio actual por WhatsApp antes de cerrar una venta.
